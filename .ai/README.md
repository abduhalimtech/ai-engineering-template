# `.ai/` — local AI workflow artifacts

Task specifications live in `tasks/`. `AGENTS.md` at the repository root is the constitution. Do not duplicate it here.

## When to create a task file

Create `tasks/TASK-NNN-short-slug.md` for non-trivial work (MEDIUM and above, or anything that needs a durable spec). Skip files for typos and other microscopic changes.

Use the section layout in `AGENTS.md`. Keep the file factual. Never paste secrets.

## Status values

Use the lifecycle names from `AGENTS.md`. Never mark a check `PASSED` without command or specialist evidence.
